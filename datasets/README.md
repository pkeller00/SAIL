# Datasets

Raw data are not redistributed. Each folder explains where to obtain a
dataset and, where needed, provides `prepare.py`, which writes the inputs
expected by the experiment configs to `data/<name>/` (git-ignored).

| Folder | Data | Used by |
|---|---|---|
| `4i/` | 4i multiplexed imaging (squidpy) | `experiments/4i` |
| `pd1_cscc/` | cSCC PD-1/PD-L1 blockade CosMx cohort | `experiments/pd1_cscc` |
| `orion_crc/` | ORION-CRC multiplexed immunofluorescence | `experiments/survival/orion_crc.yaml` |
| `tcga_brca/`, `tcga_crc/` | TCGA whole-slide images (patch features) | `experiments/survival/tcga_*.yaml` |
| `mesothelioma/` | MesoGraph St George TMA cell graphs | `experiments/mesothelioma` |
| `macroeconomics/` | Global Macro Database + Natural Earth | `experiments/macroeconomics` |

Synthetic data are generated by the experiments themselves.
